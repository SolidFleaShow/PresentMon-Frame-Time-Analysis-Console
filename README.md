## Features

- Ready-to-use capture profiles for frame time, GPU busy and latency analysis
- Benchmarking workflow guides covering repeatable test scenarios
- CSV/ETL export and data visualization templates for performance review
- Overlay integration examples with RTSS and other monitoring tools
- Per-game capture presets for consistent frame-time comparison
- Command-line automation documentation for batch benchmarking
- Step-by-step tutorials covering capture setup, filtering and analysis
- Real-world examples demonstrating efficient frame-time and latency workflows

## Requirements

- Windows 10/11
- Installed PresentMon
- Administrator privileges for some capture modes

## Usage

Open the extracted folder and explore the profile and guide directories. Run PresentMon with the included capture profiles or follow the documentation to configure frame-time tracing, export results, and visualize data. The guides provide practical instructions for each resource.

This repository contains a comprehensive set of tools, presets and educational materials designed to improve frame-time measurement, benchmarking and graphics performance analysis on Windows using PresentMon.
